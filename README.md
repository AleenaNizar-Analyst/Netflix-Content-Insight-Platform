🎬 Netflix Content Insight Platform

An interactive Excel-based data analytics and business intelligence platform developed to analyze Netflix's content library, identify content trends, perform statistical analysis, and provide searchable title-level insights.

The platform combines executive reporting, trend analysis, interactive lookups, and statistical analysis into a structured four-page Excel dashboard.

---

📊 Project Overview

The Netflix Content Insight Platform transforms Netflix content data into an interactive analytical solution using Microsoft Excel.

The project is organized into four dedicated analytical pages:

Page| Name| Purpose
01| Netflix Content Overview| Executive overview
02| Content Trends & Analysis| Main analytical insights
03| Lookups & References| Searchable title lookup and data dictionary
04| Statistical Analysis| Deeper statistical insights

The platform enables users to explore Netflix content across different dimensions including content type, country, release year, genre, rating, duration, and title-level information.

03 — Lookups & References

Purpose

Searchable Title Lookup & Data Reference

The third page is a supporting/reference page rather than another analytical dashboard.

It provides an interactive lookup table that allows users to search and filter individual Netflix titles.

Content Lookup

The lookup section includes:

- Show ID
- Title
- Type
- Director
- Cast
- Country
- Date Added
- Release Year
- Rating
- Duration
- Genre / Listed In
- Description

Users can use the lookup functionality to find detailed information about a particular Netflix title.

Data Dictionary

Field| Description
Show ID| Unique identifier for each title
Title| Name of the Netflix title
Type| Movie or TV Show
Director| Director associated with the title
Cast| Main cast members
Country| Country or countries associated with the title
Date Added| Date the title was added to Netflix
Release Year| Original release year of the title
Rating| Content rating assigned to the title
Duration| Movie runtime or number of TV show seasons
Listed In| Genre or category associated with the title
Description| Description or synopsis of the title

📈 Key Analytical Areas

Content Composition

Analysis of the overall Netflix content library and the distribution between Movies and TV Shows.

Geographic Analysis

Analysis of Netflix content across countries and comparison of Movies and TV Shows by country.

Time-Based Analysis

Analysis of release years and content growth to understand the evolution of Netflix's content library.

Genre Analysis

Identification and comparison of major genres and categories represented in the dataset.

Rating Analysis

Analysis of content ratings and their frequency across the Netflix library.

Title-Level Analysis

Interactive lookup functionality provides detailed information about individual Netflix titles.

Statistical Analysis

Descriptive statistical measures are used to examine averages, medians, minimums, maximums, frequencies, proportions, and standard deviation where applicable.
